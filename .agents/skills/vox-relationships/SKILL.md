Work from the current Vox checkout. Read `docs/RELATIONSHIP_SYSTEM_PLAN.md` for product scope and epic dependencies; read `docs/RELATIONSHIP_OPERATIONS.md` only for runtime or rollout work. Preserve the user's requested scope and current authorization.

Choose the relevant role from [role contracts](references/roles.md). Delegate independent work when useful; avoid assigning overlapping file ownership. Use `gpt-6.1-sol` for cross-system contracts, privacy, concurrency, and independent review; use `gpt-6-luna` for bounded UI, fixtures, documentation, and routine synthetic users when those models are available and authorized. Record actual model identities rather than substituting names in reports.

Scoped source events feed an assessor for preferences, situations and typed intentions. Deterministic audience/control/temporal gates precede composition of one fresh complete draft with at most one question; the composer may omit it when none is useful. `OpenAIFollowUpReview` evaluates exact-draft meaningful continuity and content compatibility as two independent typed predicates (continuity ≥0.80, content violation ≤0.10); server code then rechecks fresh authorization, epoch/revision and transport fences. The older four-way `OpenAIDecisions` evaluator is historical evidence only, not current runtime. Shadow assesses a supplied turn only and does not create an outbox, foreground reply or memory or perform full draft review. Never treat Decisions as the event database or imply observational logging trains a model.

Keep ordinary friendly initiative natural. Respect explicit topic boundaries, corrections, pauses, and stops. Silence is missing evidence, and choosing silence is a valid result. A private fact or relationship preference cannot cross to another person or group without its recorded audience authorization. Persona, mood hypothesis, communication preferences, and objective source facts have different lifetimes.

Temporal evidence requires a literal current-source quote, caller-attached source ID, source time and timezone; model-derived ISO dates are not independent date proof. `after_event` needs a known end, future starts are preparatory, ongoing events do not imply completion, reschedules refresh windows while preserving kind unless purpose changes, and unknown timing fails quiet. Feedback is only explicit and same-private-audience, linked to the exact latest assistant intention marker and matching epoch within seven days; silence, replies and politeness are not success. For acceptance, exercise behavior through the actual integration surface relevant to the change. `npm run test:relationships` covers core invariants; `src/lib/relationships/simulation/README.md` explains deterministic replay and independent real-model user roleplay. Distinguish fake-clock behavior, fake transport, real provider, browser, emulator, and live delivery evidence. Keep transcripts fictional and outside operational telemetry.

Deliver changed files, concrete verification, unresolved risks, and the next release gate. Deployment, model access, scheduler, and actual recipient delivery are separate facts. A synthetic-user task alone does not authorize messages to real people.
