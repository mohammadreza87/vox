# Reviewed private memory / حافظهٔ خصوصیِ بررسی‌شده

## Delivered / پیاده‌سازی

EN: In Privacy, select 2–8 existing own saved notes in one Work/Personal space and one currently allowed agent. Create a proposed summary, inspect its ephemeral plain-text preview, then separately choose **Save reviewed summary**. The preview discloses export of only selected notes to the configured AI provider. Discard saves nothing. Existing delete controls delete a summary while preserving originals; deleting a source also invalidates and purges its derived summaries. No automatic collection, shared/group summary, publication, or optional consent is introduced. Existing `explicit.memory_request` authority governs this explicit request; relationship-only `optional.auto_memory` is never reused.

FA: در حریم خصوصی، ۲ تا ۸ یادداشت ذخیره‌شدهٔ خود را از یک فضای کاری یا شخصی و یک عامل مجاز انتخاب کنید. پیش‌نمایش موقتِ متنی خلاصه را بسازید و بررسی کنید، سپس جداگانه «ذخیرهٔ خلاصهٔ بررسی‌شده» را بزنید. پیش از درخواست، ارسال فقط همین یادداشت‌ها به ارائه‌دهندهٔ هوش مصنوعی توضیح داده می‌شود. کنارگذاشتن، چیزی ذخیره نمی‌کند. حذف خلاصه اصل یادداشت‌ها را نگه می‌دارد؛ حذف منبع، خلاصه‌های مشتق از آن را نامعتبر و متنشان را پاک می‌کند. جمع‌آوری خودکار، خلاصهٔ گروهی یا مشترک، انتشار یا رضایت اختیاری تازه اضافه نشده است. اختیار همان درخواست صریح حافظه است؛ رضایت حافظهٔ خودکارِ مخصوص روابط دوباره استفاده نمی‌شود.

## Contract / قرارداد

- `POST /api/studio/adaptive/reviewed/preview`: signed Telegram authentication, membership, same origin, bounded JSON, exact private space/agent, unique `{id,revision}` sources; only selected note text reaches the LLM. At most 12,288 input bytes, 700 requested output tokens, 2,000 output characters / 8,192 bytes; provider waiting is bounded to ten seconds and forwards cancellation. Provider truncation is rejected.
- `POST .../reviewed/accept`: explicit immutable text + signed preview receipt. HMAC receipt binds account/person/binding/current authority, exact agent/space/source versions, content hash, nonce and at most 120-second expiry. Atomic acceptance is idempotent; deletion/rollback never rearms an accepted nonce.
- Stored rows add optional strict `sourceRefs`; ordinary notes do not gain feature fields. Ancestor revisions/space/status/expiry and cycle/depth bounds govern every derived read. Expiry never exceeds the earliest source. Canonical reads, mutations and lifecycle sweeping purge invalid derived text. No provider text or query is logged by this feature.
- Summary generation and save require supported **single-process FILE** authority snapshots and the Anthropic adapter's qualified configured-fetch fence. Fresh canonical/Studio authority is checked before actual transport fetch, after provider return, before HTTP delivery, and after temporary-file fsync immediately before synchronous atomic rename. An account lock prevents concurrent canonical mutation during save; Studio and clock are rechecked last. Malformed/busy/unsupported snapshots fail closed. Ordinary notes keep their existing adapter behavior. Gemini and distributed summary generation/save remain unavailable.
- Retrieval requires its existing personalization consent and exact agent grant. Preferences stay first; memory and summary rows rank by query relevance, with summary only a tie-break. A summary suppresses an original only after fitting the 8,192-byte / 12-item pack and preserving its normalized whole-statement sequence. Omitted exact dates/details, swapped negation/entity/date associations, irrelevant summaries and oversize summaries preserve source fallback. This is deterministic lexical EN/FA selection, not semantic fidelity verification by a model.

FA: پیش‌نمایش و ذخیره به احراز هویت امضاشده، عضویت فعلی، مبدأ یکسان، فضای خصوصی و عامل دقیق و نسخهٔ دقیق منابع وابسته‌اند. رسید امضاشده حداکثر ۱۲۰ ثانیه اعتبار دارد؛ ذخیره اتمی و تکرارپذیر است و حذف، رسید را دوباره فعال نمی‌کند. تغییر، حذف یا انقضای منبع، متن مشتق را از خواندن خارج و در مسیرهای چرخهٔ عمر پاک می‌کند. ساخت و ذخیرهٔ خلاصه فقط در فایلِ تک‌فرایندی و انتقال واجد کنترل Anthropic فعال است؛ قفل، خرابی یا ذخیره‌ساز پشتیبانی‌نشده به رد امن منجر می‌شود و یادداشت‌های عادی کار می‌کنند. اختیار و ساعت، پیش از انتقال واقعی شبکه و آخرین جایگزینی اتمی فایل دوباره بررسی می‌شوند. بازیابی همچنان به رضایت شخصی‌سازی و عامل دقیق نیاز دارد؛ ترجیحات صریح مقدم‌اند و خلاصه‌ها بر اساس ارتباط با پرسش رتبه می‌گیرند. اصل یادداشت تنها وقتی حذف می‌شود که خلاصه واقعاً در بودجه جا شود و توالی جمله‌های آن را حفظ کند؛ جزئیات حذف‌شده و جابه‌جایی نفی یا تاریخ باعث حفظ منبع می‌شوند. این گزینش واژگانی است و تضمین صحت معنایی مدل نیست.

## Downgrade / بازگشت نسخه

EN: New readers accept old documents. An older strict reader cannot read derived `sourceRefs`. Before downgrade, stop summary producers and use `pruneFileReviewedMemory` in `src/lib/adaptive/reviewed-memory/rollback.ts` with one explicit absolute FILE directory and account ID. Default is dry-run returning only change status and a content digest. Apply additionally requires `producersStopped:true` and that exact `expectedContentSha256`; it acquires the account lock and compares current contents. It removes complete derived rows only, preserving original notes, current rights, all unrelated state and acceptance tombstones. Never restore an old account backup. The pure scoped projection is available for review; a Firestore operational migration is unsupported.

FA: خوانندهٔ تازه دادهٔ قبلی را می‌پذیرد، اما خوانندهٔ سخت‌گیر قبلی فیلد منابع مشتق را نمی‌شناسد. پیش از بازگشت نسخه، تولید خلاصه را متوقف کنید و ابزار بالا را برای یک پوشهٔ مطلق فایل و یک حساب مشخص اجرا کنید. حالت پیش‌فرض فقط بررسی و گزارش هش است. اعمال، توقف تولیدکننده و همان هش محتوا را می‌خواهد و زیر قفل حساب انجام می‌شود. فقط ردیف‌های مشتق حذف می‌شوند؛ اصل یادداشت‌ها، حقوق فعلی، دادهٔ نامرتبط و سابقهٔ پذیرش باقی می‌مانند. پشتیبان قدیمی حساب را جایگزین نکنید. مهاجرت عملیاتی Firestore پشتیبانی نشده است.
