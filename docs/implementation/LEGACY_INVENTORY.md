LIP1 is a pure, local planner for explicitly supplied synthetic JSONL fixtures. It recognizes eight native-shaped formats: Tireh FileState, Tireh documents, organization configuration, contact memory, legacy user settings, chat documents, local chat arrays, and Studio state. It returns an in-memory inventory/quarantine plan. Every row remains target-null, current authority unverified and use denied. Historical notification flags, names, source identifiers, scopes, share offers or safety controls do not establish consent, identity, ownership, audience, permission or a new memory grant.

The implementation applies strict bounded parsing and accounting (16 sources, 2,000 units, 64 MiB transport, 1 MiB frame, 64 KiB chunks, 32 nested containers, 50,000 lexical tokens, 20,000 output rows, and 1,000 child occurrences per unit). Unknown fields and unenumerable containers produce incomplete/opaque inventory rather than an invented empty result. Duplicate source occurrences are retained, owner-namespaced and committed atomically.

This slice has no importer, apply, restore, destination, runtime binding, route, CLI, filesystem discovery, Firestore/Firebase reader, provider/model/network call, browser access, consent capture, or production inventory. The caller-supplied `synthetic-dry-run` label is an assertion, not proof of data provenance. No real data was read, copied or reconciled. No latency or cost improvement is claimed; this deterministic inventory task has no response-latency baseline.
