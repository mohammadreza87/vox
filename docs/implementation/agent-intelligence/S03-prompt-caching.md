# S03: Cache-stable prompt layout and the llm.ts upgrade

Step 3 of [docs/AGENT_INTELLIGENCE_SOLUTION.md](../../AGENT_INTELLIGENCE_SOLUTION.md) (sections 2.2, 2.8, 4.7 and the Step 3 row of section 5).
Base commit: `6d00b8066e5d8e8d444bb47d978aa571e20929df`. Branch: `aiq/prompt-caching-r2` (continues `aiq/prompt-caching`).

## Goal

Make the reply prompt cacheable without changing the default behaviour.

**Default (both flags unset):** every prompt string, message list and provider request body is byte-identical to base 6d00b80. Two goldens guard this: `cached-prompt-baseline` (generated in the branch's first commit) and `cached-prompt-flag-off` (generated by running the test file against a `git archive` export of the base).

**Behind `TIREH_CACHED_PROMPT=1`**, `composeReply` and `liveTurn` send:

| Part | Content | Cache |
|---|---|---|
| System block A | Persona: identity, character, voice, craft, examples, rules. No date. Padded to at least 512 approximate tokens. | 1 h |
| System block B | The org snapshot, exactly where the base renders `## Organization` (private, Work, no guests). Keyed by a content hash. | 1 h |
| System block C | The chat frame: conversation, audience, guest rules, live information, voice capability, capabilities, L2 hooks, the live or proactive frame, and a note on the per-turn block. | 5 min |
| History | Replayed byte-identically. One breakpoint on the assistant turn just before the newest user run. | 5 min |
| `## For this turn` | Appended to the newest user turn as a text block: date, reply format, group speaker, `<active_skill>`, clipped memories with provenance, conflicts, adaptive saved context, relationship context, final reminder. | none |

Nothing is unshifted as a first user message any more.

**`TIREH_PROMPT_SYSTEM_TAIL=1`** is the A/B arm: in non-search `composeReply` turns, the per-turn block goes out as a trailing `{role:'system'}` message. It needs `TIREH_CACHED_PROMPT=1`. Web-search turns and `liveTurn` always use trailing text.

`effort` stays `'low'` for every chat reply under both flag values. The doc gate (`cache_read_input_tokens` of at least 70% in staging) is measured after merge from the existing `captureUsage`/`observedUsage` trace fields.

## Expected flag-on failures in unmodified suites

`TIREH_CACHED_PROMPT=1 npx vitest run src/lib/tireh` fails exactly 10 base tests. In each, the test's own fake calls `request.system.startsWith`, reads saved context at `messages[0]`, or compares the newest message exactly. Each one has a passing port.

| Suite | Tests |
|---|---|
| `gateway.test.ts` | "a failed memory extraction does not break the reply"; the history-reset fence (private, group); the forgetting fence (private, group) |
| `history-privacy.test.ts` | "fences an extraction completing after source deletion"; "stops extraction and new history after withdrawal…"; "keeps Personal isolated from legacy Work and presents explicit context as data" |
| `diagnostics.test.ts` | "keeps extraction exceptions private…" |
| `voice-delivery.test.ts` | "answers a typed caption in a hasGuests group from the caption alone" |

The spec's 8 or 9 omitted the voice-delivery caption test. That test compares the newest message with `toEqual`, and that message now also carries `trailingText`.

## Deviations from the step spec

- **`TURN_NOTE` wording.** It quotes the heading as `"For this turn"`, without `## `. Block C sits before the history breakpoint, and the wire test forbids `## For this turn` there.
- **Personal turn.** It carries no reply-format line, matching the base: the base personal prompt never had one.
- **`placeTurn` with no messages.** It pushes an empty-content user turn that carries the block. Callers never hit this.
- **Flag-off golden rebased onto main (merge onto `agent-intelligence-wave-a-main`).** Main's 962e877 (group agents) changed the legacy prompt after base 6d00b80, so `cached-prompt-flag-off.base.json` was regenerated the same way against a `git archive` export of origin/main `7224f40d69cf816a49139a30092cbf92551d2a8e`. The merged tree reproduces main's flag-off bytes; the prompt-layout block A snapshot gained only 962e877's "Always answer in words" rules line.
- **The flag-off golden is not the branch's first commit.** The earlier engineer's `cached-prompt-baseline` golden is that first commit. The spec-named `cached-prompt-flag-off.base.json` was generated by running the same test file against an export of the base. Both are single-add files.

## Risks

- **Reply quality.** Memories and saved context now sit in the user role. Mitigations: the turn note, `FINAL_REMINDER` closing the block, and `plain()`/JSON escaping. Red-team in EN and FA before enabling.
- **System tail arm.** Haiku 5.5 may treat mid-conversation system messages as untrusted. The arm is off by default.
- **Breakpoint budget.** A, B, C and the history marker use all 4 breakpoints.
- **Model minimums.** 512 is Haiku's floor; the Sonnet, Opus and Fable floors may be higher. Block A is about 1,400 approximate tokens for the test persona.
- **1-hour writes.** They cost 2x.
- **Timing laps.** Under the flag, saved-context selection runs before `lap('prompt')`, so flag-on and flag-off stage timings are not directly comparable.
- **Merge.** Code merged later that reads `request.system` must use `systemText()`.
