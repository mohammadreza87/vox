## Review boundaries

Studio access and canonical account authority live in separate stores. Fresh checks before provider calls narrow the race window; they do not provide a transaction across those stores or an external provider. Analytics consent/grants remain the authority for the local content-free journal. A Studio block racing an already-started journal append can leave minimized metadata until its ordinary purge; blocked agents are excluded from visible projections. A block is not represented as an analytics-consent withdrawal.

Reminder transport additionally reads validated committed canonical and Studio file snapshots synchronously immediately before its single fetch, after all awaited work. This closes the reproduced late canonical withdrawal race in the supported single-process file/polling topology. An active canonical writer lock defers an unattempted alert safely; malformed or unsupported snapshots deny the send. This is not a distributed transaction or a guarantee against arbitrary separate-process writers, and does not retract an already-started provider request.

Compatibility utilities remove only each subsystem's new metadata under an explicit single-account compare-and-swap lock. They preserve authored memories, current rights and deletion records. Stop producers, preserve protected evidence and validate the exact old schema before binary rollback; restoring an old account backup is not a rollback procedure.

## خلاصهٔ فارسی

این مرحله یادآورهای درخواستی، اندازه‌گیری محدود مراحل پاسخ و مصرف گزارش‌شدهٔ ارائه‌دهنده، و مسیر آماده‌سازی از گفتار موقت را به بخش‌های موجود وصل می‌کند. هر قابلیت اختیاری به مجوز مشخص و انتخاب جداگانهٔ فرد وابسته است. متن اعلان تلگرام جزئیات خصوصی یادآور را ندارد؛ ارسال نامطمئن دوباره به‌صورت خودکار انجام نمی‌شود. گزارش کاربر دربارهٔ نتیجهٔ کار، تأیید مستقل موفقیت نیست.

مجوز جداگانهٔ یادآور پس از نمایش و تأیید نسخهٔ جاری، حداکثر ۳۰ روز و تا پایان مجوز هدف و قابلیت معتبر است. پایان نشست تعاملی ۱۲ ساعته، اعلان عمومیِ از قبل درخواست‌شده را متوقف نمی‌کند؛ اما این انتخاب دسترسی خصوصی، خروجی داده، ایجاد یا تعویق یادآور و تحلیل رفتار را تمدید نمی‌کند. انتخاب قدیمی به تأیید تازه نیاز دارد. تمدید فقط اعلان‌های زمان‌بندی‌شده و همچنان مجاز را منتقل می‌کند؛ ارسال در حال انجام را تمدید نمی‌کند و اعلان نامطمئن یا یادآور فقط در صندوق را فعال نمی‌کند. پاک‌کردن هویت، مجوز یادآور را حذف می‌کند.

## Compiled error-boundary correction

The connected compiled run exposed a real bundle-boundary defect: a service created by instrumentation threw `AdaptiveError(409, invalid_transition)`, but a separately bundled route failed `instanceof` and returned generic 503. Domain constructors now carry immutable shared-symbol brands; HTTP boundaries validate only own bounded data fields and map supported errors consistently. Unbranded shapes, proxies, getters, unsupported status/code values and private messages remain generic failures. The same correction covers adjacent shared-memory conflicts, rate limits and LLM authorization cancellation. Independent review passed 48 tests across seven files plus full TypeScript; the author selected 128 tests across ten files. A rebuilt real HTTP check is required to close the original compiled-path gate.

آزمون نسخهٔ کامپایل‌شده نشان داد تفاوت بسته‌های کد، خطای معتبر ۴۰۹ را به ۵۰۳ تبدیل می‌کرد. نشانگر مشترک و تغییرناپذیر اکنون تشخیص خطای داخلی را ممکن می‌کند و دادهٔ خصوصی خطا بازگردانده نمی‌شود. ۴۸ آزمون مستقل و بررسی TypeScript موفق شدند؛ بازآزمایی مسیر واقعی HTTP روی خروجی تازه لازم است.
